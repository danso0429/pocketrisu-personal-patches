# Archived records

These files are historical validation receipts, audits, and handoffs for work
that no longer describes the current patcher:

- `POCKETRISU-1.9-*` — the PocketRisu 1.9.0 rebase and its per-feature
  validation. The current catalog targets only PocketRisu 1.10.0.
- `POCKETRISU-KEI-*` and `kei-overlap-audit/` — Kei integration status,
  overlap audits, and per-child validation from the 1.8.1/1.9.0 period. The
  active Kei planning authority remains
  [`../POCKETRISU-KEI-INTEGRATION-CATALOG.md`](../POCKETRISU-KEI-INTEGRATION-CATALOG.md).
- `PATCHER-TARGET-SCOPED-UNITS-VALIDATION.md` — the manager receipt for
  exact-target unit scoping before its first version-scoped consumer.

The records are kept as they were written, except that results and references
of the retired exhaustive combination verifier were removed. Paths inside them,
such as `docs/POCKETRISU-1.9-REBASE-AUDIT.md`, name each file's original
location; the file now lives in this directory under the same name.
