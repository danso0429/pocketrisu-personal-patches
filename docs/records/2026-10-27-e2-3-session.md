### Terms used

- **PocketRisu**: the upstream application the patcher modifies. The live install runs 1.10.0; this work moves the patch set to **1.16.1** ("native" = unmodified upstream 1.16.1 code).
- **Patcher**: the public repository of patch packs (`pocketrisu-personal-patches`). A **pack** is one feature; a **unit** is one anchored edit inside a pack (file, anchor, replacement, `targetVersions`, `requires`).
- **E2**: the plan step "rebase every pack onto PocketRisu 1.16.1". Sub-steps: E2-0 baseline and pack-versus-native audit, E2-1 subset harness and independent packs, E2-2 client build fence and snapshot core, E2-3 `lazy-chat-sync` rebuilt as units over native 1.16.1 (E2-3a decisions, E2-3b durable writes, E2-3c storage reset barrier, E2-3d chat revision protocol, E2-3e startup/plugin load order), E2-4 to E2-9 later packs, review and cutover. **E3** is a later step added in this session (BG admission and re-render fixes).
- **Planning repo**: the repository holding the BG canon (`docs/BG-PRESERVE-ORDERED-GOALS.md`) and the per-step plans (`docs/BG-E2-*-PLAN.md`).
- **Subset harness**: a maintainer tool added in E2-1a. It copies pristine 1.16.1, applies a chosen set of packs, runs `pnpm install/test/test:compat/check/build`, re-plans (expects 0 changes) and reverts (expects 0 leftovers). "closure" = one pack and its dependencies; "bundle" = all packs already rebased.
- **A4 / A6b**: E2-1 acceptance checks. A4 = subset harness per pack and for all packs together; A6b = the real installer must refuse `apply` on 1.16.1 for packs not declared for it.
- **Candidate gate**: the 19-step patcher gate run against PocketRisu 1.10.0 (used until the E2 branch became 1.16.1-only).
- **Blind tests**: tests written before implementation from the plan only. Each test carries `[new]` (must fail before implementation, on a behavior assertion) or `[unchanged]` (must pass before implementation). **Receipt check**: the orchestrator runs the received tests once (three times for `[unchanged]`) and compares results with the tags.
- **Roles**: orchestrator = the main Claude session; `opus-implementer`, `sonnet` (general-purpose subagent on Sonnet) and `haiku-explorer` = Claude subagents; **Astra** = Codex `gpt-6-astra` plan reviewer; **Codex sol** = `gpt-6.1-sol` code reviewer; **Codex tester** = `gpt-5.6-sol` blind-test author; **Argon** = Gemini 4 Argon through the Antigravity CLI (test scenarios, and in this session a code-review trial); **opencode** = OpenCode Go with `deepseek-v4.1-flash` (evaluation only).
- **Bug protocol**: the project rule that after the same defect family appears twice, patching stops; the orchestrator writes a structure report and the user approves the structural fix.
