### Terms used

- **PocketRisu**: the upstream application the patcher modifies. The live install runs 1.10.0. This work moves the patch set to **1.16.1** ("native" = unmodified upstream 1.16.1 code).
- **Patcher**: the public repository of patch packs. A **pack** is one feature; a **unit** is one anchored edit inside a pack. `patches/target-coverage.cjs` records, for each 1.10 unit, whether it is `retained`, `rewritten`, `replaced`, `retired` or newly `added` on 1.16.1.
- **E2**: the plan step "rebase every pack onto PocketRisu 1.16.1". Sub-steps used in this record: E2-3 `lazy-chat-sync` (chat save/sync protocol) rebuilt as units over native 1.16.1; E2-3d2 to E2-3d5 follow-up fixes to its chat revision protocol; E2-3e client startup safety; E2-4a to E2-4d later pack groups. **E2-9** is the live cutover; nothing in this record touches live.
- **Slot**: the place in the in-memory database where an open chat lives (`db.characters[c].chats[i]`). The **slot base** is the last server-confirmed revision the client uses to compute a delta and to detect conflicts.
- **Subset harness**: `scripts/qualify-subset.cjs`. It clones pristine 1.16.1, applies a chosen set of packs, runs `pnpm install/test/test:compat/check/build`, re-plans (expects 0 changes) and reverts (expects 0 leftovers). **Closure** = one pack and its dependencies; **bundle** = all packs already rebased (seven packs during E2-3, eight after E2-4b, nine with E2-4c).
- **Blind tests / fixed tests**: tests written from the plan before the implementation exists. Each carries `[new]` (must fail before implementation, on a behavior assertion) or `[unchanged]` (must pass before implementation). **Receipt check**: the orchestrator runs received tests once (`[unchanged]` three times) and compares results with the tags. Implementers may not edit fixed tests; corrections are made by a test author on a tree without the implementation.
- **Roles**: orchestrator = the main Claude session; `opus-implementer` = Claude Opus implementer subagent; **Sonnet** = general-purpose Claude Sonnet subagent; `haiku-explorer` = read-only Claude Haiku explorer; **Astra** = Codex `gpt-6-astra` plan reviewer; **Codex tester** = Codex `gpt-5.6-sol` blind-test author; **Codex sol** = Codex `gpt-6.1-sol` code reviewer; **Argon** = Gemini 4 Argon (medium) through the Antigravity CLI.
- **Codex fallback**: when a Codex role cannot run because of its usage limit, plan and code reviews go to Sonnet (xhigh effort) and Argon in parallel, and test authoring goes to Sonnet. Every fallback output is listed in a batch index (**INDEX**) for one Codex re-check after the Codex weekly reset (2026-11-02 06:34Z).
- **Decisions file**: a local log of every decision the orchestrator took in the user's place during the delegated period (rows P1-P2 and A1-A26).
