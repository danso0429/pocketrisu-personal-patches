## Resulting behavior

The unchanged original PageFold provider can use its default primary font and persistent cache through the isolated host. Its accepted floating statistics bookkeeping finishes before ordinary callback scope release. Native/browser UI remains native; the separately selected native preset/model adapter is not substituted for the original plugin-provider caller. No plugin name/hash allowlist or script rewrite is introduced.

Local storage top-level strings have a32MiB JSON budget and stream through fixed-position private descriptors and64Ki-code-unit string slices. Ordinary/root/nonstring values retain4MiB; root writes retain8MiB. Local pending accounting is separate (32MiB plus8192-byte envelope), with64 writes/64MiB per operation. Transfers share32Mi-code-unit ownership; trusted store parse/copy uses4x encoded-byte allocation credits, capped256MiB. These are bounded accounting, not absolute host RSS or immediate-GC promises.

The worker resource contract is512MiB with V8heap256MiB, retaining aggregate1GiB, CPU/task/filesystem/network and8MiB frame/16MiB queued-byte/16MiB-per-second guards. A15s progress deadline is bounded by runtime. Incoming quota contention publishes an awaited mandatory warning before API effects. Malformed descriptors are protocol failures. Outgoing values retain scope until drain/cancel/close; duplicate replies and aliases cannot manufacture another dispatch.

Callback bookkeeping joins only its invocation's accepted RPC chains, through two quiet turns and a bounded15s settlement warning. It retains the original callback result/error. Abandoned network/model work and unused bodies retain their existing abort-on-return behavior; arbitrary delayed non-RPC work is not promised completion.

A local CAS refusal preserves the competing value, awaits a mandatory partial-processing warning, and returns the API rejection to the unchanged script. A script that catches it can preserve its already obtained answer. Uncaught provider errors, lost identity/permission, root/argument failures and mandatory-notice failures still reject; this is not an implicit successful default provider. The parent-owned operation-keyed v2 message is reclaimable after ACK and does not consume terminal-failure receipts; repeated phases remain deduplicated within the operation. Unlike ordinary message overflow, failure to store this warning is critical. No storage merge, provider replay or key-specific exception is used.
